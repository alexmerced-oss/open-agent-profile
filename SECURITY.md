# Security policy

Report vulnerabilities that would let a profile widen authority, execute during resolution, persist instructions as trusted state, expose credentials, escape a workspace, or corrupt concurrent writes through GitHub private vulnerability reporting for this repository. Do not include live credentials or private user data in a public issue.

Ordinary specification ambiguities and hardening proposals belong in public issues. Supported security fixes target the latest OAP 1.x maintenance release. A security correction that changes interoperability is published as normative errata with tests and a changelog entry.
