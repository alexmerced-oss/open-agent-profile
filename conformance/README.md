# Machine-readable conformance results

[`result.schema.json`](result.schema.json) defines the portable OAP conformance-result format. Checked-in records in [`results/`](results/) are self-declared implementation evidence tied to the exact fixture Git revision recorded in each file; they are not certifications and do not automatically apply to later fixture changes.

Verify their schema, empty failure set, full Git revision, and complete required-ID surface for the claimed level:

```console
python tools/verify_conformance_results.py
```

CI runs the same verifier. A new result should be generated by the implementation's own conformance suite, committed in that implementation repository, and copied here without modification with an implementation-report link to its source.
